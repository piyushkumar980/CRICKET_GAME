Cricket Game
A fun and interactive cricket-themed game created using HTML, CSS, and JavaScript, where the user plays against the computer by choosing between bat, ball, and stump. The game determines the winner based on a random selection by the computer and keeps track of the user's wins.

How to Play
Choose Your Action:
Select between bat, ball, or stump.

Computer's Turn:
The computer will randomly select one of the three options.

Determine the Winner:

If your choice beats the computer's choice, you win.
If the computer's choice beats yours, computer wins.
If both choices are the same, it’s a tie.
Track Your Wins:
The game displays the total number of times you have won.

Game Rules
Bat vs Ball: Bat wins (Player hits the ball successfully).
Ball vs Stump: Ball wins (Ball hits the stumps).
Stump vs Bat: Stump wins (Bat misses the stump).
Same Choice: It’s a tie.
Features
Interactive UI:
An engaging interface designed with HTML and CSS.

Random Selection:
The computer makes its choice randomly using JavaScript.

Score Tracking:
Keeps track of the user's wins dynamically.

Installation and Setup
Clone or download the repository.
Open the index.html file in any modern web browser.
Play the game directly—no additional setup is required.
Technologies Used
